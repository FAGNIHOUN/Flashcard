Flashcard Generator 📚

Bienvenue dans le projet Flashcard ! Cette application vous permet de créer et de réviser des flashcards, idéale pour l'apprentissage des langues ou toute autre matière. 
Avec des fonctionnalités telles que la catégorisation des cartes et le suivi de votre progression, cet outil vous aidera à améliorer vos compétences de manière efficace et ludique.

Table des matières


Fonctionnalités

- Création de Flashcards** : Ajoutez facilement des cartes avec une question et une réponse.
- Catégorisation : Organisez vos flashcards en différentes catégories pour un apprentissage ciblé.
- Suivi de progression : Marquez les cartes comme "maîtrisées" ou "non maîtrisées" pour suivre vos progrès.
- Stockage local : Toutes les flashcards sont stockées dans le `localStorage` pour une utilisation hors ligne.

Technologies utilisées

ReactJS

## Installation

Pour utiliser l'application, suivez ces étapes :

1. Clonez le dépôt :
   ```bash
   https://github.com/FAGNIHOUN/Flashcard.git
   ```
2. Accédez au répertoire du projet :
   ```bash
   cd flashcard
   ```
3. Exécuter dans votre navigateur.
   ```bash
   npm run dev
   ```

Utilisation

1. Créer une Flashcard : Remplissez les champs pour la question et la réponse, puis cliquez sur "Ajouter".
2. Réviser les Flashcards : Parcourez vos cartes et essayez de répondre aux questions.
3. Marquer comme maîtrisée : Si vous avez bien répondu, marquez la carte comme maîtrisée.
4. Catégoriser : Ajoutez vos cartes à des catégories spécifiques pour une meilleure organisation.
